# Nobre Leads Engine

Crie uma landing page moderna em formato de quiz de alta conversão para o curso "Dono que Anuncia", da Nobre Academy.

Objetivo:

Converter empresários e donos de pequenos negócios em compradores do curso através de um diagnóstico personalizado.

Estilo visual:

- Design premium e minimalista.

- Preto, branco e vermelho como cores principais.

- Visual moderno inspirado em SaaS de alto padrão.

- Bordas arredondadas.

- Muito espaço em branco.

- Ícones modernos.

- Animações suaves.

- Totalmente responsivo.

- Carregamento rápido.

- Aparência profissional.

Estrutura:
